# Reading list: Agentic RAG and failure diagnosis

Separate reading branch on Enron emails and privacy-preserving RAG: [Enron papers](../enron-papers/README.md). These studies do not change the numbering of the main 24-paper list below.

Separate 10-paper reading branch on adaptive RAG selection and trade-offs: [Adaptive RAG papers](../adaptive-rag-papers/README.md). This branch also preserves the main list's numbering.

These 24 papers support the exploratory literature review. Papers 01-15 follow the main reading path: agent behavior and adaptive retrieval, question types and benchmarks, evaluation and trade-offs, then failure diagnosis and observability. Papers 16-20 form an optional branch on deciding whether to use tools and finding relevant tools in large catalogs. Papers 21-24 are selected additions on question decomposition, active retrieval, and multi-hop benchmark design. The numbering is an organizational order, not a ranking of quality or a requirement to read every paper sequentially. These are **research papers**, not the document corpus that the chatbot will eventually retrieve from.

| File | Official paper page | What to focus on |
| --- | --- | --- |
| [01 - ReAct](01-ReAct-Tool-Using-Agents.pdf) | [Yao et al., ICLR 2023](https://arxiv.org/abs/2210.03629) | The action/observation pattern behind tool-using agents. |
| [02 - IRCoT](02-IRCoT-Iterative-Retrieval.pdf) | [Trivedi et al., ACL 2023](https://aclanthology.org/2023.acl-long.557/) | Why multi-step questions can require iterative retrieval. |
| [03 - Adaptive RAG](03-Adaptive-RAG.pdf) | [Jeong et al., NAACL 2024](https://aclanthology.org/2024.naacl-long.389/) | How question complexity changes the useful retrieval strategy. |
| [04 - Self-reflective RAG](04-Self-Reflective-RAG.pdf) | [Asai et al., ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/25f7be9694d7b32d5cc670927b8091e1-Paper-Conference.pdf) | On-demand retrieval and self-critique; adaptive RAG, not a general multi-tool agent. |
| [05 - Corrective RAG](05-Corrective-RAG.pdf) | [Yan et al., 2024 arXiv preprint](https://arxiv.org/abs/2401.15884) | Evaluate retrieved evidence and trigger corrective retrieval or web search. Its CRAG acronym is different from paper 07's benchmark. |
| [06 - MultiHop-RAG](06-MultiHop-RAG-Benchmark.pdf) | [Tang and Yang, COLM 2024; arXiv version](https://arxiv.org/abs/2401.15391) | Questions requiring evidence across documents. The local PDF is the arXiv v1 paper. |
| [07 - CRAG benchmark](07-CRAG-Question-Benchmark.pdf) | [Yang et al., NeurIPS 2024](https://arxiv.org/abs/2406.04744) | Question categories, simulated APIs, and evaluation design. This is *Comprehensive RAG Benchmark*, not *Corrective RAG*. |
| [08 - RAG evaluation (RAGAS)](08-RAG-Evaluation-RAGAS.pdf) | [Es et al., EACL 2024](https://aclanthology.org/2024.eacl-demo.16/) | Reference-free evaluation of retrieval and answer quality; distinguish quality scoring from failure localization. |
| [09 - RAG diagnostics (RAGChecker)](09-RAG-Diagnostics-RAGChecker.pdf) | [Ru et al., NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/27245589131d17368cccdfa990cbf16e-Abstract.html) | Fine-grained retriever/generator diagnostics for conventional RAG; identify what agent traces would add. |
| [10 - Agentic vs Enhanced RAG](10-Agentic-vs-Enhanced-RAG.pdf) | [Ferrazzi et al., ACL 2026](https://aclanthology.org/2026.acl-industry.5/) | The closest direct comparison; inspect baselines, controls, task types, and cost. |
| [11 - Agentic search cost](11-Agentic-Search-Cost.pdf) | [McCleary and Ghawaly, 2026 preprint](https://arxiv.org/abs/2603.08877) | Controlled search-budget, retrieval, accuracy, and cost comparisons. |
| [12 - RAG scaling](12-RAG-Scaling-BM25-vs-Agent.pdf) | [Wang et al., 2026 preprint](https://arxiv.org/abs/2607.26497) | Why corpus size and a strong lexical baseline matter in agent comparisons. |
| [13 - Agentic RAG hop diagnosis](13-Agentic-RAG-Hop-Diagnosis.pdf) | [You et al., ACL Findings 2026](https://aclanthology.org/2026.findings-acl.66/) | Hop-level validation: where multi-step retrieval reasoning goes wrong. |
| [14 - Agent failure localization (AgentRx)](14-Agent-Failure-Localization-AgentRx.pdf) | [Barke et al., 2026 arXiv version](https://arxiv.org/abs/2602.02475) | Critical failure-step labels, root-cause categories, and diagnosis from agent execution trajectories. |
| [15 - Trace depth and failure attribution](15-Trace-Depth-Failure-Attribution.pdf) | [Chen et al., ACL 2026](https://aclanthology.org/2026.acl-long.912/) | Partial versus full trace observability for failure attribution. This studies multi-agent systems, not specifically RAG. |
| [16 - MetaTool](16-MetaTool-When-Which-Tool.pdf) | [Huang et al., ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/bc12914d66b41b6bfc2d3a5decdb498b-Abstract-Conference.html) | Separate the decision to use a tool from choosing which tool; study single- and multi-tool selection. |
| [17 - ToolLLM](17-ToolLLM-Large-API-Retrieval.pdf) | [Qin et al., ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/28e50ee5b72e90b50e7196fde8ea260e-Abstract-Conference.html) | Large API catalog, neural API retriever, and tool-use benchmark; read the retrieval sections selectively. |
| [18 - Re-Invoke](18-ReInvoke-ZeroShot-Tool-Retrieval.pdf) | [Chen et al., EMNLP Findings 2024](https://aclanthology.org/2024.findings-emnlp.270/) | Zero-shot tool retrieval using enriched tool descriptions, intent extraction, and similarity ranking. |
| [19 - ToolRet](19-ToolRet-Retrieval-Benchmark.pdf) | [Shi et al., ACL Findings 2025](https://aclanthology.org/2025.findings-acl.1258/) | Benchmark tool retrieval separately from ordinary document retrieval and from final task success. |
| [20 - PORTS](20-PORTS-Tool-Selection-Retriever.pdf) | [Molfetta et al., EMNLP 2025](https://aclanthology.org/2025.emnlp-main.507/) | Train a retriever to select tools useful to the downstream LLM; an advanced method, not a required implementation choice. |
| [21 - Self-Ask](21-Self-Ask-Question-Decomposition.pdf) | [Press et al., EMNLP Findings 2023](https://aclanthology.org/2023.findings-emnlp.378/) | Explicit follow-up questions and search as an alternative to IRCoT-style reasoning sentences. |
| [22 - FLARE](22-FLARE-Active-Retrieval.pdf) | [Jiang et al., EMNLP 2023](https://aclanthology.org/2023.emnlp-main.495/) | Decide when and what to retrieve during long-form generation; not the same task as multi-hop QA. |
| [23 - HotpotQA](23-HotpotQA-MultiHop-Questions.pdf) | [Yang et al., EMNLP 2018](https://aclanthology.org/D18-1259/) | Multi-hop question types and sentence-level supporting facts; focus on dataset design. |
| [24 - MuSiQue](24-MuSiQue-MultiHop-Benchmark.pdf) | [Trivedi et al., TACL 2022](https://aclanthology.org/2022.tacl-1.31/) | Construct connected multi-hop questions and reduce shortcut-based answering. |

Read **01-15 in numerical order** for the main path. For tool discovery, read **16-20 in order** if needed. After paper 03, papers **21-22** offer useful alternatives to compare with adaptive or iterative retrieval. Read **23-24** selectively when designing multi-hop questions or choosing benchmarks. The additions are optional and do not settle the thesis direction. Read the original papers before quoting numbers or reproducing an experimental setup; do not rely on filenames or this brief guide as a substitute for their methods and limitations.
